# anhangá.tech — site

Site institucional da anhangá.tech. React + Vite + TypeScript + Tailwind.

## Rodar localmente

**Pré-requisitos:** Node.js 24, [pnpm](https://pnpm.io) (via `corepack enable`)

1. Instalar dependências:
   `pnpm install`
2. Rodar o app:
   `pnpm dev`
3. Checar tipos:
   `pnpm typecheck`
4. Build de produção:
   `pnpm build`
